# Deferred cases

Explicitly deferred work is parked here. These cases are not the default main aim of the next phase or sprint, and a general `next` request does not reopen them. Explicit user reactivation of the case or its behavior is required before planning it through the normal sprint Yes/No gate.

Each record keeps its source authorization, reason, missing acceptance, evidence links, Coverage limitation and reopening/closure conditions. Historical plans, progress and completion receipts remain unchanged; these entries consolidate their known deferrals rather than claiming new test results. Unapproved Contract decisions and ordinary unfinished work are not automatically deferred cases. This directory survives phase evidence cleanup.

When a case is explicitly reactivated, retain its history and link the user request and approved sprint. Mark it resolved only after the stated checks actually pass and the results are reviewed; record resolution evidence without erasing its prior limitations. An available prerequisite alone is not authorization. Do not assign a target sprint, date or owner without evidence.
