# PH-003-B1 — SIWE field-like statement parsing

- **Status:** DEFERRED; not repaired or accepted as compliant.
- **Origin:** PH-003, original B1; T02 and full WG-003-A1 acceptance.
- **Authorization and reason:** The [approved PH-003 amendment](../plans/history/PH-003.md#approved-ph-003-scope-amendment--2026-11-01) records the user instruction: “Defer this statement-parsing edge case, retain WG-003 as PARTIAL, and finish PH-003’s remaining work.” The callback-only integration could not repair upstream pre-callback parsing.
- **Missing behavior:** Accept a legal SIWE statement such as `Expiration Time: 2020-01-01T00:00:00Z` when it is statement text, without treating it as a protocol expiration field. Preserve actual validity checks and the original signed bytes.
- **Evidence:** [PH-003 B1 investigation](../plans/progress/PH-003.md#reproducible-blockers-and-exact-unblock) records Better Auth 1.7.11 rejecting this control before WalletGate's callback. These are historical observations, not a fresh reproduction or proof that every current dependency version has the defect.
- **Coverage:** WG-003 remains PARTIAL. Deferral does not waive ERC-4361 interoperability or authorize upstream patches, dependency upgrades, identity/session policy changes or a replacement endpoint.
- **Reopening condition:** An explicit user request naming B1 or requesting this deferred statement-parsing repair. A general next-sprint request or a generated proposal does not reactivate it. Obtain normal sprint execution approval after planning.
- **Closure criteria:** A supported production integration accepts valid field-like statements, rejects actual expired/not-yet-valid and malformed messages, verifies original signatures, preserves durable nonce/session behavior, and passes the affected end-to-end OAuth/RP acceptance. Retain actual source/version/test evidence and review the outcome.

This directory entry consolidates the existing deferral. It does not amend historical scope, approve implementation or schedule this case as the next sprint objective.
